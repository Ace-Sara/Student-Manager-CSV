# Student Manager CSV

A simple Python OOP project for managing student information using a CSV file.

## Features

* Read student data from a CSV file
* Store students as Python objects
* Calculate the average grade
* Find the student with the highest grade
* Handle common CSV and file errors

## Technologies

* Python
* Object-Oriented Programming (OOP)
* CSV
* Git & GitHub

## Project Structure

```text
Student-Manager-CSV/
├── day1.py
├── students.csv
└── README.md
```

## How to Run

Make sure Python is installed, then run:

```bash
python day1.py
```

The program reads the data from `students.csv` and displays the average grade and the student with the highest grade.

## Example

The program can produce output similar to:

```text
46.71
Mobina
90
```

## Learning Goals

This project was created as a practical exercise to improve Python OOP, CSV file handling, error handling, and Git/GitHub workflow.
